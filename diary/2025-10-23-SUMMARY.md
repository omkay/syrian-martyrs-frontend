## 🔧 Issues Fixed

### 1. Docker Build Failures
**Problem**: Dockerfiles expected lock files in each service directory
**Solution**: Modified Dockerfiles to use `npm install --legacy-peer-deps` without requiring lock files

Files modified:
- `/web/Dockerfile.dev`
- `/api/Dockerfile.dev`

### 2. Missing lib/utils.ts
**Problem**: Components importing from `@/lib/utils` but file didn't exist in web/
**Solution**: Created `/web/lib/utils.ts` with cn() utility function

### 3. Missing Dependencies
**Problem**: web service missing bcryptjs and jsonwebtoken
**Solution**: Added to web/package.json:
```json
{
  "dependencies": {
    "bcryptjs": "^3.0.2",
    "jsonwebtoken": "^9.0.2"
  },
  "devDependencies": {
    "@types/bcryptjs": "^3.0.0",
    "@types/jsonwebtoken": "^9.0.10"
  }
}
```
